# E-Commerce Sales & Profit Intelligence Dashboard

## 📊 Project Overview

This project analyzes e-commerce sales performance to understand revenue, profitability, customer segments, order behavior, geographic performance, and product return patterns.

The project uses Python for data generation and preparation and Power BI for data modeling, DAX calculations, interactive analysis, and dashboard development.

The objective is to transform raw transactional data into a business-focused executive dashboard that helps stakeholders understand overall performance and identify areas requiring attention.

---

## 🎯 Business Problem

An e-commerce business needs to understand:

- How much revenue and profit is being generated?
- Which product categories contribute the most revenue?
- Which customer segments generate the most value?
- Which cities contribute significantly to sales?
- What percentage of orders are returned?
- Which categories have higher return rates?
- How are orders distributed across different statuses?
- How does revenue and profit change over time?

The goal is to answer these questions through an interactive Power BI dashboard.
